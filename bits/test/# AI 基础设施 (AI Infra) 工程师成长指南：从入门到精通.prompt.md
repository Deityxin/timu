# AI 基础设施 (AI Infra) 工程师成长指南：从入门到精通

这份指南专为大二学生设计，旨在将复杂的 AI Infra 领域拆解为可操作的学习步骤。

## 1. 到底什么是 AI Infra? (通俗版)

如果把训练大模型比作 **“开赛车”** (算法工程师负责开车调参)，那么 AI Infra 工程师就是 **“造赛车引擎和铺赛道的人”**。

- **你的任务**：让车跑得更快（计算加速）、更稳（分布式训练不挂）、更省油（显存优化）。
- **核心能力**：
  1.  **C++**: 因为 Python 太慢了，引擎必须用 C++ 造。
  2.  **CUDA**: 因为 CPU 算不过来，必须指挥显卡 (GPU) 的几千个核心同时算。
  3.  **系统**: 理解数据在内存、显存、硬盘之间怎么搬运最快。

## 2. 学习路径 (按顺序来)

### 阶段一：打地基 (大二下)
**目标**：脱离“做题家”思维，学会写“能跑在生产环境的高性能代码”。

| 学习重点 | 为什么学？ | 推荐资源 (必看) |
| :--- | :--- | :--- |
| **现代 C++** | 算法题用的 C++ 很浅。你需要在大项目里管理内存，不让程序崩掉。 | 📘 书：《C++ Primer》(当字典查)<br>📺课：Cherno C++ (B站搜，讲得极好)<br>📘书：《Effective Modern C++》(进阶必读) |
| **操作系统 (OS)** | 理解线程、进程、锁、缓存。不懂这些写不出高并发程序。 | 📘书：《深入理解计算机系统 CSAPP》(神书，必读)<br>📺课：南京大学蒋炎岩《操作系统》(B站神课) |
| **Linux 基础** | AI 训练全在 Linux 服务器上，不会命令行寸步难行。 | 📺课：【马哥教育】Linux从入门到精通 (B站随便找个基础教程看) |

**✅ 阶段考核项目**：
- 用 C++ 写一个简单的**矩阵乘法** (`Matrix Multiplication`)，对比一下 3 层 for 循环和 `std::vector` 的速度。

---

### 阶段二：入场券 —— CUDA 编程 (大三上)
**目标**：学会指挥 GPU 干活。这是 AI Infra 的核心壁垒。

| 学习重点 | 为什么学？ | 推荐资源 (必看) |
| :--- | :--- | :--- |
| **GPU 架构** | 了解 GPU 里的 SM、Core、显存是怎么摆放的。 | 📄文档：NVIDIA CUDA Programming Guide (官方文档最好)<br>📺课：CUDA Mode (GitHub/B站上有) |
| **CUDA C** | 在 C++ 里写 Kernel 函数，通过 `<<<grid, block>>>` 启动 GPU 线程。 | 📘书：《CUDA C 编程权威指南》<br>📂代码：[CUDA-Mode/lecture_notes](https://github.com/CUDA-MODE/lectures) |
| **性能分析** | 学会用 Nsight Systems 看看到底是哪行代码卡住了 GPU。 | 📺官方视频：NVIDIA Developer YouTube 频道 |

**✅ 阶段考核项目**：
- 手写一个 **CUDA 版 Softmax** 算子。
- 把它封装成 Python 可以调用的库 (用 `pybind11`)。

---

### 阶段三：造轮子 —— 深度学习框架原理 (大三下)
**目标**：不再只做“调包侠”，而是去拆解 PyTorch 内部是怎么实现的。

| 学习重点 | 为什么学？ | 推荐资源 (必看) |
| :--- | :--- | :--- |
| **计算图** | 理解 PyTorch 的 `autograd` (自动求导) 是怎么算出梯度的。 | 📺课：李沐《动手学深度学习》(必看)<br>📂项目：[Karpathy/micrograd](https://github.com/karpathy/micrograd) (手写微型引擎) |
| **模型推理** | 训练好的模型怎么部署？了解 ONNX 格式和 TensorRT。 | 📄文档：ONNX Runtime 官方文档<br>📺课：TensorRT 官方入门教程 |

**✅ 阶段考核项目**：
- 跟着 Karpathy 的视频，用 Python/C++ 写一个不到 100 行的小型自动求导引擎。

---

### 阶段四：从单机到集群 (大四)
**目标**：搞定大模型训练（分布式）。

| 学习重点 | 为什么学？ | 推荐资源 (必看) |
| :--- | :--- | :--- |
| **分布式训练** | 一张卡放不下 LLaMA 70B，怎么切分模型？(DDP, Pipeline Parallel)。 | 📄论文：Megatron-LM, DeepSpeed<br>📺课：HuggingFace 分布式训练文档 |
| **通信库** | 多张显卡之间怎么交换数据？(NCCL, Ring AllReduce)。 | 博客：搜“NCCL 原理”或“Ring AllReduce 算法” |

---

## 3. 现在你需要做什么？(Immediate Actions)

1.  **不要焦虑**：这个路线图是 2-3 年的量，不要指望一周学会。
2.  **配置环境**：
    - 你的电脑有 NVIDIA 显卡吗？
    - **有**：装好 WSL2 (Windows Subsystem for Linux) + CUDA Toolkit。
    - **没有**：去注册 Colab (Google) 或者 AutoDL (国内租卡平台)，几块钱就能租个 GPU 玩一天。
3.  **开始第一个任务**：
    - 去 B 站搜 **“南京大学 蒋炎岩 操作系统”**，先看前 3 集。这是中文计算机很多人的启蒙课。
    - 买一本或下载 PDF **《C++ Primer 第五版》**，放在桌头当工具书。
